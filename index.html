UI Experiments

Small, self-contained prototypes for trying out interface ideas. Each experiment is plain HTML, CSS and JavaScript that runs in the browser with no build step.

  • Required-field indicators

    Eleven live concepts for telling people which form fields are required, and which they can skip, before they press Submit, without using asterisks. Includes a study of how a progress rail adapts to multi-column forms.
