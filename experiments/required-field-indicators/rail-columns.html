Progress rail in columns

Concept C puts one mark on the rail per field, which only works when every field has its own row. In a grid, fields share rows, so each mark on the rail has to stand for something else. These are three choices for what it stands for. Use the Phone switch to see how each one collapses.

Preview

Row glyphs

Each mark on the rail stands for a row. It's a small pill with one mark per column, in the same order as the fields, so the left mark is the left field. Rings fill as their field becomes valid, small dots are optional fields, and the pill outline turns green when everything required in that row is done.

On a phone

  • The grid stacks to one column and each pill splits back into one ring per field, which is concept C unchanged

Trade-offs

  • Closest to the original rail and still says which field in a row is missing
  • Marks get small; past three columns per row they're hard to read
Needed Optional

Rail per column

Each column is its own group with its own rail and its own count. This fits when the columns mean something, like "About you" beside "Your request", and people finish one before starting the other.

On a phone

  • The columns stack into two short rails, one after the other; nothing else changes

Trade-offs

  • Wrong for paired fields like First | Last, where people read across, not down
  • Tab order runs down the left column first, so the layout has to read that way too
  • Two rails side by side is busier
Needed Optional

Section rail

The rail moves up a level, with one mark per section. Each mark is a progress ring that fills as that section's required fields are done. Inside a section the fields can sit in any grid, and a small ring or dot before each label says which ones are needed.

On a phone

  • Section grids stack to one column; the rail and its rings don't change

Trade-offs

  • Scales to long forms and any grid, including three or four columns
  • Needs real sections; a one-section form gains nothing
  • Two kinds of marks to learn: rings for sections, small marks for fields
Needed Optional
